# Git Workflow & Commit Rules

## Mandatory Branch & Sync Rules
1. Whenever code changes are made, verified, and completed, **always commit the changes and push them to the `development` branch** (`git push origin development`).
2. Always write clean, descriptive commit messages matching standard conventional commit conventions (e.g., `feat: ...`, `fix: ...`, `refactor: ...`).
3. Ensure the working tree is clean and synchronized before concluding any task.
